🚀 DevOps Portfolio Website

A modern and responsive DevOps Portfolio Website built using HTML, CSS, and JavaScript to showcase my skills, projects, and journey as an aspiring DevOps Engineer.

This project focuses on creating a clean professional personal website that can be deployed on any static hosting platform such as AWS S3, GitHub Pages, or Nginx server.
